# Illustrative demo

These assets use fictional projects, messages, times, and images. They are an
illustration of supported workflows, not a recording of a live Telegram chat.
The Chinese progress text is generated by the real `progress_card.render`
function; the surrounding Telegram-style UI is a static presentation.

Generate the fixture text, then serve this directory locally:

```sh
python3 docs/demo/render.py
python3 -m http.server 8769 --bind 127.0.0.1 --directory docs/demo
```

Open `http://127.0.0.1:8769/?stage=1` in a browser at 1280 × 760. Stages 0–3 show
project selection, two updates of the same progress message, and image delivery.
The GIF advances between still frames faster than a real task; it never contacts
Telegram, reads private runtime state, or starts a Codex turn.

Use only fabricated data when refreshing these public assets.
